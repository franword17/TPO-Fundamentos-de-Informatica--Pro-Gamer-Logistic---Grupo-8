# TPO Fundamentos de Informatica: Pro-Gamer Logistics - Grupo 8

DESCRIPCIÓN: Sistema de gestión de los productos que comercializa la empresa Pro-Gamer Logistics.

FUNCIONES: 

- Informe de los productos: muestra en pantalla el listado de productos con sus respectivas características: identificador, marca, descripción, categoría,  cantidad en stock, precio.

- Registrar productos nuevos.

- Modificar características de los productos.

- Eliminar un producto.
